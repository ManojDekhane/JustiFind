⚖️ JustiFind

Bringing justice closer to every hand — making law simple and understandable for all.

🧩 Overview

JustiFind is a smart legal assistant that helps users find which law applies to their problem in simple language.
It explains complex IPC and IT Act sections in an easy and interactive way using AI-based semantic search and a chatbot that understands natural language.

🚀 Features

🔍 Smart Legal Search: Type any legal issue in your own words.

💬 Interactive Chatbot: Get instant, conversational legal guidance.

⚡ Instant Law Lookup: Shows relevant IPC/IT Act sections in seconds.

🧠 AI-Powered Understanding: Uses semantic search (NLP) for context-based matching.

📖 Simplified Legal Explanations: Converts legal text into human-friendly language.

🌐 Future Scope: Voice input, multi-language support, and law summarization.

🧑‍💻 Tech Stack

Frontend: React.js

Backend: Python (Flask / FastAPI)

Core Logic: semantic_search.py — performs AI-based keyword and context matching

⚙️ How to Run the Project
🔸 1. Clone the Repository
git clone https://github.com/ManojDekhane/JustiFind.git
cd JustiFind

🔸 2. Run the Backend (Python)
python semantic_search.py


Backend will start at http://localhost:5000

🔸 3. Run the Frontend (React)
1. cd frontend
2. npm install
3. npm run dev

📘 Example Use Case

User Query: “My Instagram account got hacked.”
Response: IT Act, Section 66C — Identity Theft
Explanation: Using someone’s online identity or password without permission is a punishable cybercrime.
